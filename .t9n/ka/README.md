# WZRDLOG — AGENTS.md პრომპტი კოდის დამწერი AI აგენტებისთვის

`AGENTS.md` AI აგენტს დისციპლინირებულ შემსრულებლად აქცევს, რომელსაც მეხსიერება აქვს. აგენტი
სამუშაო ჩანაწერებს `WZRDLOG*` ფაილებში ინახავს: ამოცანა, roadmap, წარუმატებლობები, წარმატებები,
შეზღუდვები, ხელახლა გამოსაყენებელი ფრაგმენტები და თქვენი ტერმინების ლექსიკონი. მათ ვერსიებს
**მხოლოდ ლოკალურ** git-ტოტში, `WZRDLOG`-ში, ინახავს, თქვენს რეალურ ისტორიას კი სუფთად ტოვებს.

## რატომ

- აგენტებს სესიებს შორის ყველაფერი ავიწყდებათ. WZRDLOG აძლევს მათ მეხსიერებას, რომელიც სესიებს გადაურჩება და საკუთარი git-ისტორია აქვს.
- აგენტები წარუმატებელ მიდგომებს იმეორებენ. WZRDLOG აიძულებს მათ, წარუმატებლობები ჩაიწერონ და ხელახლა წაიკითხონ.
- აგენტები push-სა და გამოქვეყნებას ზედმეტად ადვილად აკეთებენ. WZRDLOG git-ს ლოკალურად ინახავს, ჩანაწერების push-ს hook-ით კრძალავს და მათ npm-ში არ უშვებს.
- გრძელ პრომპტებს უგულებელყოფენ. AGENTS.md არის ჩეკლისტი შემოწმებებით და ზუსტი ბრძანებებით, და არა პროზა.

## სწრაფი დაწყება

1. დააკოპირეთ `AGENTS.md` (და, თუ გსურთ, `HUMANS.md`) თქვენი პროექტის ძირში.
2. თუ თქვენი აგენტი `AGENTS.md`-ს თავისით არ კითხულობს, მიუთითეთ მასზე. Claude Code-ისთვის შექმენით `CLAUDE.md` ერთი ხაზით:
   ```md
   @AGENTS.md
   ```
3. დაიწყეთ სესია. პირველ გაშვებაზე აგენტი:
   - შეამოწმებს საქაღალდეს და საჭიროების შემთხვევაში გაუშვებს `git init`-ს;
   - დაამატებს `WZRDLOG*`-ს `.gitignore`-ში;
   - დააყენებს დამცავ `pre-push` hook-ს და თავის სკრიპტებს `.git/wzrdlog/`-ში;
   - ერთხელ გკითხავთ ენისა და დიზაინის პრეფერენციებზე.

## უკვე გაქვთ AGENTS.md

- თქვენი პროექტის წესები `AGENTS.md`-ის დასაწყისში დატოვეთ, მათ ქვემოთ კი ჩასვით WZRDLOG-ის პროტოკოლი — `# AGENTS.md — WZRDLOG protocol`-იდან ბოლომდე. პროტოკოლი თვითკმარია და დანომრილ სექციებად არის დაყოფილი, ამიტომ არ არის დამოკიდებული იმაზე, რაც მის ზემოთ წერია.
- პროტოკოლი არ შეინახოთ ფაილში, რომლის სახელი `WZRDLOG`-ით იწყება. ასეთი ფაილი `WZRDLOG*`-ს დაემთხვევა და git მას უგულებელყოფს.
- თუ პროექტს უკვე აქვს საკუთარი `HUMANS.md`, აგენტი არც მას წაიკითხავს. ყველაფერი, რაც აგენტმა უნდა იცოდეს, `AGENTS.md`-ში გადაიტანეთ.
- `CLAUDE.md`, `.cursorrules` და მსგავსი ფაილები შეიძლება დარჩეს. ოღონდ ისინი `AGENTS.md`-ზე უნდა მიუთითებდნენ და არ უნდა იმეორებდნენ მის შიგთავსს.
